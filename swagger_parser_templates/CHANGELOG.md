# Changelog

## 1.1.0

* Updates the minimum `swagger_parser` version to 2.1.0.
* Exposes `unmatchedUnionValues` and structural union fallback names to templates.

## 1.0.1

* Updates `swagger_parser` to 2.0.1 and defaults required-field inference to `false`.
* Exposes operation `returnType` and `emptySuccessStatuses` to templates.
* Adds a runnable template example and public API documentation.

## 1.0.0

* Initial release.
