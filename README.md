Parse Swagger 2.0 and OpenAPI 3.0–3.2 from JSON or YAML. Generate Dart models
and clients for Retrofit + Dio, Dio, or package:http. Use the CLI, Dart API,
or browser editor.

## Projects

| Folder | Purpose |
| --- | --- |
| [swagger_parser](swagger_parser) | Dart generation, CLI, and configuration. |
| [swagger_parser_core](swagger_parser_core) | Versioned OpenAPI models, parsing, validation, and reference resolution. |
| [swagger_parser_templates](swagger_parser_templates) | Optional Mustache templates, helper files, and template CLI. |
| [swagger_parser_pages](swagger_parser_pages) | Jaspr browser editor with config, templates, and ZIP downloads. |
| [swagger_parser_tests](swagger_parser_tests) | Generated-code builds and runtime tests on VM and Chrome. |
